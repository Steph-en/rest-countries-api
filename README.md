## Install all dependencies
Run `npm install`

## API configuration

Create local environment files from the safe examples before building or serving:

```sh
cp src/environments/environment.example.ts src/environments/environment.ts
cp src/environments/environment.development.example.ts src/environments/environment.development.ts
```

Replace `YOUR_API_KEY` in both local files. These files are ignored by Git. An API key included in an Angular app is visible to browser users; use a backend to keep a key private.
